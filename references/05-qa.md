# 05 · 质检清单

## 一、机器能查的（跑脚本）

```bash
python scripts/check_pack.py <成品目录>
```

脚本会逐张读 PNG 头，检查：

- 尺寸对不对（主图 240×240 / 缩略图 120×120 / 封面 240×240 / 图标 50×50 / 横幅 750×400）
- 体积超没超（500KB / 50KB / 30KB）
- 有没有 alpha 通道（主图、缩略图、封面、图标必须有）
- 文件名有没有补零到两位
- 主图张数够不够 16 / 24

**有一条 FAIL，就先修，别急着看第二遍。**

## 二、机器查不了的（必须肉眼逐格数）

三张九宫格拼起来看，逐格过这五项：

| 项 | 怎么数 |
|---|---|
| 尾巴 | 一条。多一条就是模型幻觉 |
| 腿 / 爪 | 四条腿、每只爪子的趾头数一致 |
| 手 | 每只手最多四根手指，没有多出来的手 |
| 道具 | 有没有穿模（筷子插进脸里、杯子穿过手） |
| 文字 | 有没有压到脸、有没有出画布、有没有错字 |

**别只看"背景白不白"就说干净。** 背景干净和角色画对是两件事，两条尾巴那格我夸过它干净。

## 三、交付前最后一遍

- [ ] 24 张主图全是 240×240、RGBA、≤500KB
- [ ] 24 张缩略图 120×120、≤50KB
- [ ] 封面脸在圆形安全区内，无文字
- [ ] 图标只有头肩，无方框背景
- [ ] 横幅不是纯白底、不带文字
- [ ] 赞赏两张文案只有一句人话
- [ ] 文件命名补零
- [ ] `送审信息.md` 逐张含义词齐全
- [ ] `QA.md` 里记录了脚本输出和肉眼核对结果
- [ ] 字体是可商用的那款
