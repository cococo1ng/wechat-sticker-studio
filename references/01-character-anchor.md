# 01 · 角色设定卡与锚定段

> 本文里的「团子」是**虚构的教学示例**，用来演示字段怎么填。
> 换成你自己的角色时，八项照这个密度写就行。

## 一、设定卡（八项，缺一项就别往下写提示词）

```markdown
| 字段 | 内容 |
|---|---|
| 名字 | 团子 |
| 身份 | 一只圆滚滚的糯米团子精灵（虚构示例） |
| 外形 | 正圆形身子，直径约等于身高；短手短脚；主体米白 #F7E6C4，描边深灰 #3A3A3A，腮红 #F2A9A0 |
| 表情特征 | 两颗黑豆点眼，嘴一条短弧线；笑的时候眼睛变月牙 |
| 标志物 | 头顶一片小绿叶，叶柄朝右 |
| 性格 | 憨、慢半拍、护食 |
| 反差梗 | 软得像没骨头，但谁抢它吃的就跟谁急 |
| 口头禅 | "再来一口" |
```

### 写法要求

- **外形只写画得出的**：物种、体型比例、眼睛形状、配饰位置和颜色。不写"可爱""治愈"这种形容词——那是结果不是画法。
- **配色给 HEX，不给形容词**。"暖色调"三个字等于没说；`#F7E6C4` 才能被画出来。
- **反差梗一句话说清**。这是 24 张里最值钱的两个动作的来源。
- **口头禅 ≤6 字**，要能直接印在表情上，不要标点堆叠。

## 二、锚定段

作用：让 24 张看起来是同一个人。**只写不变的东西。**

### 中文版

```
角色锚定：圆形糯米团子精灵「团子」，身子正圆、短手短脚、无脖子，主体米白色（#F7E6C4），
描边深灰色（#3A3A3A），两颊淡腮红（#F2A9A0），黑色豆点眼、短弧线嘴，
头顶一片朝右的小绿叶。扁平卡通插画风，粗描边、纯色块、不画阴影渐变，
正面偏四分之三视角，全身入画，白色纯背景。
```

### 英文版（一整段，不换行）

```
Character anchor: "Tuanzi", a round glutinous-rice-ball spirit with a perfectly circular body, short arms and legs, and no neck; body cream-white (#F7E6C4), bold dark-grey outline (#3A3A3A), soft blush on both cheeks (#F2A9A0), black dot eyes, short curved mouth, one small green leaf pointing right on top of the head. Flat cartoon illustration, bold outline, solid colour blocks, no gradients or shading, three-quarter front view, full body, plain white background.
```

### 正反例

| 写法 | 判断 |
|---|---|
| 只写"一只可爱的团子精灵" | ❌ 每次出来的颜色、比例、眼睛都不一样 |
| 写"看起来很高兴，正在招手" | ❌ 动作写进了锚定段，24 张会全是一个姿势 |
| 给 3 个 HEX + 配饰位置 + 描边色 | ✅ 可复现 |
| 锚定段单独一块，提示词里只写 `[此处粘贴锚定段]` | ✅ 省字数、不容易漏 |

### 三条铁律

1. **锚定段不写动作、场景、情绪。**
2. **每条提示词都粘它**，别指望模型记得上一张。
3. **英文版控制在 120 词内**，即梦对超长英文会截断。

## 三、换成你自己的角色

复制上面那张表，八项全部替换。**注意保留三样东西**：

1. 配色给 HEX
2. 标志物要有一个"每次都能画出来"的固定位置
3. 反差梗要一句话能说完

填完先别急着出图，把锚定段单独丢给模型出一张正面全身——**这张不对，24 张全白做。**
