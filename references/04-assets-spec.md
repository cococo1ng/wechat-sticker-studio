# 04 · 配套图与上传规格

## 一、尺寸与体积（硬门槛，出图前就按这个做）

| 图 | 像素 | 体积上限 | 透明底 | 内容要求 |
|---|---|---|---|---|
| 主图 | 240×240 | ≤500KB | 要 | 单个动作，白描边 |
| 缩略图 | 120×120 | ≤50KB | 要 | 主图同源缩放 |
| 封面 | 240×240 | ≤500KB | 要 | 脸在圆形安全区内，无文字 |
| 聊天面板图标 | 50×50 | ≤30KB | 要 | 只截头肩，不要方框背景 |
| 详情页横幅 | 750×400 | ≤500KB | 不用 | 不带文字，不要纯白底 |
| 赞赏引导图 | 750×560 | — | — | 一句引导语 + 角色 |
| 赞赏致谢图 | 750×750 | — | — | 一句致谢语 + 角色 |

> 平台会改版，上传前以页面当时显示的数值为准；上面这组是目前实际能过的值。

## 二、横幅 750×400 的排版公式

```
左：留白 8%，一条 6×150 的竖色条（主色）
右上：标题 ≤10 字，字号 48–56
标题下：副标题 ≤18 字，字号 22–26，颜色压暗 20%
底部 1/3：角色横向排列（2–3 个动作），脚底对齐同一条基线
背景：同色系浅渐变，不铺纯白
```

三条禁令：**图里不写字**（平台自己会叠标题）、**不用纯白底**（会像没做完）、**不拉伸**（角色等比缩放，脚底对齐）。

## 三、赞赏图 750×560 / 750×750

```
750×560 引导图：左侧竖色条 + 主文案（50 字号）+ 副文案（24 字号）+ 角色在右下
750×750 致谢图：角色居中偏上，底部 1/4 深色块放致谢语（28 字号），可加碎彩纸装饰
```

文案只写一句人话，例如「请我喝碗热汤」「谢谢你呀」。**别写"打赏""付费"**。

## 四、上传顺序（顺序错了会错位）

微信表情开放平台里：

```
1. 先传：详情页横幅 → 封面 → 聊天面板图标
2. 再传：赞赏引导图 → 赞赏致谢图
3. 最后传：表情主图（01…24）+ 逐张填「含义词」
4. 填名称、简介、分类、版权声明 → 提交审核
```

**为什么先传配套图**：如果先传表情，平台会把后面传的横幅当成第 17 张表情，整个顺序全乱，只能删了重传。

## 五、常见驳回原因

| 驳回说法 | 真实原因 | 怎么改 |
|---|---|---|
| 图片尺寸不符 | 主图不是 240×240，或带了边距 | 按表重新导出，不要用截图 |
| 存在非透明背景 | 背景是 RGB 白而不是 alpha 0 | 重新泛洪去背，存 RGBA |
| 含有文字水印 | 图上留了生成工具的水印或签名 | 裁掉或重出 |
| 含义词与图片不符 | 逐张含义词复制粘贴了同一句 | 逐张写，且与画面动作对应 |
| 涉嫌侵权 | 角色像某个已有 IP，或字体非商用 | 换角色/换 OFL 字体 |
| 内容低俗 | 动作或文案擦边 | 换掉那一张，别赌 |

## 六、送审信息模板

```markdown
## 基本信息
- 名称：<≤8 字>
- 简介：<一句话，说清什么角色、什么场景用>
- 分类：<日常 / 情绪 / 职场 / 方言 …>
- 角色设定：<三行，谁、长什么样、什么性格>

## 逐张含义词
01 打招呼
02 比心
…

## 版权与授权
- 角色原创：是 / 否（否的话写授权来源）
- 字体：站酷快乐体（SIL OFL 1.1，免费商用）
- 图像生成方式：AI 生成 + 人工修图（按平台要求如实标注）
```
