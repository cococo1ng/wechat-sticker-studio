# 02 · 九宫格提示词（即梦口径）

## 一、三张九宫格怎么分工

| 张 | 格子内容 | 说明 |
|---|---|---|
| 第 1 张 | 日常高频：你好、谢谢、好的、收到、笑、哭、困、生气、⑨备用 | 这套的"底子" |
| 第 2 张 | 情绪强度：爆笑、崩溃、无语、委屈、震惊、害羞、白眼、鼓掌、⑨备用 | 聊天里用来"顶情绪" |
| 第 3 张 | 场景专用：加班、吃饭、睡觉、出门、催更、再见、加油、摸鱼、⑨备用 | 决定了这套能不能被反复用 |

**第 ⑨ 格永远写"备用/任意安全姿势"**——崩掉的那格用它补位，不用重出整张。

## 二、提示词的固定结构（每一张都一样）

```
[此处粘贴锚定段]
画面：3×3 九宫格，等分九格，格子之间留 2% 白边。
第1格：<姿态+表情+道具>
第2格：……
第9格：<备用，一个不容易崩的姿势>
画风：扁平卡通、粗描边、纯色块、无阴影渐变、白色背景。
画面要求：不要文字、不要水印、不要多余手指、不要多出一条尾巴、不要背景装饰、不要真实照片质感。
比例 1:1，每格内容居中，角色全身完整不裁切。
```

### 五个硬要求

1. **中英双版都要有**。英文版一整段，**≤1400 字**，不能有空行、不能有 `---`、不能套代码围栏。
2. **九格必须写死**，不能写"九个不同的开心表情"——那是让模型自由发挥。
3. **负向词写进正向句末**。即梦没有负向词输入框，"不要什么"只能写在「画面要求」里。
4. **锚定段只出现一次**，其余格描述里不要再重复外形。
5. **每格只做一件事**。一格又想招手又想哭，出来必糊。

## 三、英文版示例（可直接套）


## 五、补救句（一次出对是意外，出不对才正常）

| 现象 | 补救句（直接追加到提示词末尾） |
|---|---|
| 出来的图里有字 | `画面中不要出现任何文字、字母、数字、符号。` |
| 格子之间有空隙或错位 | `九格严格等分，格子之间只有 2% 白色间隔，角色不跨越格子边界。` |
| 角色变成了别的物种 | `保持角色锚定段里的物种、配色、配饰完全一致，不要改变物种。` |
| 塑料感 / 3D 感 | `扁平二维卡通插画，纯色块平涂，不要 3D 渲染、不要塑料高光。` |
| 多手指、多尾巴 | `手部每只手最多四根手指，尾巴只有一条。` |
| 背景有装饰 | `纯白色背景，不要任何背景装饰、不要地面阴影。` |

## 六、生成参数

- 比例 **1:1**，九宫格一次出 9 格
- 先传参考图（前一张九宫格里最好看的一格），强度 **0.55–0.75**
- 强度 >0.8 姿势会被锁死；<0.5 角色会跑形
- 一张九宫格出 3–4 次是正常成本，别一次没成就换提示词
